# 检索结果页交互修正与阅读计划恢复门禁

本文件是最新需求，覆盖此前“删除阅读计划”的决定；其余视觉返工和真实数据边界继续有效。

## 1. 阅读状态与筛选条件必须分离

当前缺陷：`阅读状态`和`筛选条件`都打开同一个右侧筛选面板。

最终行为：

- `阅读状态 ▾`：打开锚定在按钮下方的轻量 Popover，不得打开右侧筛选栏。
- Popover 项目：全部文献、未读、阅读中、已读、重点；每项显示真实数量（没有聚合计数时省略数字，不写死）。
- 当前状态带勾选；选择后更新 `read_status`/重点相关真实查询参数、回到第 1 页、同步 URL、关闭 Popover。
- `筛选条件`：只负责展开/收起桌面右侧栏，或在窄屏打开筛选 Drawer；不得改变阅读状态。
- 两个按钮分别具有独立 open state、焦点管理、Esc 关闭和点击外部关闭。
- 增加直接组件/E2E 测试，证明点击两个按钮出现的是不同内容且互不串联。

## 2. 年份筛选必须可操作

当前缺陷：年份范围控件不可点击/拖动。

最终设计：

- 使用真正可交互的双端年份范围，允许独立调整起始年和结束年。
- 起止范围来自真实 facet/15 年业务边界；保证 `from <= to`。
- `近1年 / 近3年 / 近5年 / 自定义`均可点击，选中项有清晰状态。
- 自定义后拖动/键盘方向键可调整；两个 thumb 均有可访问名称和当前值。
- 调整期间显示待应用值；点击右栏底部 `应用筛选 · N篇` 后请求服务端、更新 Chip、回到第1页并同步 URL。
- 如果后端目前只支持单年份，必须补齐服务端 `year_from/year_to` 范围查询、facet、导出参数透传及直接 API 测试，不能制作只能看的假滑条。

## 3. 修复 20 条后的服务端分页

当前缺陷：首页只显示 20 条且没有下一页入口。

最终设计：

- 列表头右侧显示：`筛选后 N 篇  ‹  1–20 / N  ›`。
- 当 `filtered_total > 当前页末序号` 时，下一页按钮必须启用；第一页上一页禁用；末页下一页禁用。
- 底部分页可保留完整页码器；至少必须有上一页、下一页、当前范围和总数。
- page/page_size 必须进入真实请求与 URL；默认每页 20 条，与 UI 文案一致。
- 切页后保留筛选、排序、Tab，滚动回列表顶部；旧请求不能覆盖新页。
- 测试至少覆盖 21、40、41 条三种边界、筛选后总数变化、前进后退和刷新恢复。

## 4. 恢复并重新设计阅读计划

### 4.1 顶部 Tab

顺序固定为：

`全部文献 N | 阅读计划 N | 重复文献 N`

这是替换关系，不是新增第四个 Tab：删除顶部“已保存”Tab，将其位置、视觉样式和视图语义改为“阅读计划”。

- 阅读计划是结果集合内的真实视图，不是筛选侧栏选项。
- 采用与当前 Tab 完全一致的文字 + 数字 + 2px 蓝色下划线，不新增大按钮。
- 点击后加载真实已加入阅读计划的文献，URL 使用稳定的 `view=reading-plan`。
- 数字来自真实服务端；没有计数时先补接口/响应字段，不写死示例数值。
- 不再保留独立“已保存”结果视图；既有 saved 数据需要审计并安全兼容/迁移为阅读计划成员，不能静默丢失用户状态。

### 4.2 单篇按钮

在每条文献右侧操作列、PubMed/PMC 主动作上方或同一动作行放置紧凑按钮：

- 未加入：`＋ 加入阅读计划`
- 已加入：`✓ 已在阅读计划`

视觉规格：高度 28px；左右 padding 10px；字号 12px；圆角 6px；1px `#C9D8F5` 边框；白底蓝字。Hover 为极浅蓝底，已加入状态使用浅蓝底和深蓝字，不使用大面积实心蓝。

点击必须调用真实写入接口，按钮局部 loading；成功后同步单条状态、Tab 数量和当前阅读计划视图；失败回滚并提示。已加入按钮再次点击可取消，或打开小菜单提供“移出阅读计划”，二者选择一种一致实现。

### 4.3 批量按钮

选中文献后，在批量栏中显示：

`已选择 N 篇 | 加入阅读计划 | 标记已读 | 清除选择`

`加入阅读计划`采用轻量 outline；只有选择项时显示。部分失败必须报告成功/失败数，并保留失败项选中。

### 4.4 业务模型

- 优先复用现有 reading-order/阅读计划模型和 API；先审计真实语义。
- “阅读计划成员关系”与“推荐阅读顺序”若是两个概念，后端必须明确建模，不得用生成阅读顺序接口冒充加入状态。
- 若当前后端缺少持久化成员关系，先设计最小数据字段/接口、迁移和直接测试，再接前端；不得仅存在内存或前端状态。
- 不恢复“加入知识库”和“导入 PDF”。

## 5. 新增验收标准

- AC-I01：阅读状态与筛选条件打开不同控件，状态互不串联。
- AC-I02：五种阅读状态的查询、URL、计数和关闭行为正确。
- AC-I03：年份双端控件可鼠标和键盘操作，快捷范围可点击。
- AC-I04：年份范围由服务端真实过滤，导出沿用同一范围。
- AC-I05：超过20条时下一页可用，页码边界和总数正确。
- AC-I06：刷新、前进后退保留页码、筛选和排序。
- AC-I07：阅读计划 Tab 存在、计数真实、可进入并返回。
- AC-I08：单篇加入/移出阅读计划持久化，失败回滚。
- AC-I09：批量加入支持部分失败并保留失败选择。
- AC-I10：阅读计划按钮符合紧凑视觉规格且不挤压文献标题。
- AC-I11：不出现知识库或 PDF 导入入口。
- AC-I12：顶部只有“全部文献 / 阅读计划 / 重复文献”，不存在“已保存”Tab；页面操作中不存在与阅读计划语义重复的独立“保存”按钮。

每项必须有直接行为测试。完成后提供桌面截图：默认全部文献、阅读状态 Popover、年份自定义状态、第二页、阅读计划 Tab、单篇已加入状态。
