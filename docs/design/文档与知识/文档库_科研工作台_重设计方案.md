# 文档库：科研资料处理工作台重设计方案

## 设计定位

**设计阅读：这是面向本地医学科研人员的高信息密度资料处理工作台，采用克制、可追溯、低动效的科研工具语言。**

文档库不是上传页，也不是普通网盘。它的单一任务是：让用户在已归属知识库的真实文档中，快速判断资料状态、修复处理问题，并定位可用于 RAG 的内容。

本方案保留现有信息架构：知识库管理资料来源，文档库处理来源中的具体文档。文档库不恢复直接上传入口。

## 设计原则

- **来源优先**：每篇文件始终显示所属知识库和相对目录，避免跨来源文件平铺后失去出处。
- **状态优先**：解析、索引和证据可用性是操作数据，而不是装饰性的状态标签。
- **检索优先**：AI 资料导航是定位本地原文的工作工具，放在列表上方，但默认保持紧凑。
- **密度优先**：采用 4/8px 间距、13px 主文字、表格数字等宽显示，避免大卡片和过度留白。
- **不伪造**：所有统计、页码、章节、摘录、状态和错误原因必须来自实际后端数据。

## 布局结构

桌面端使用稳定的三栏工作台，最大内容宽度保持现有 1280px：

```text
┌───────────────────────────────────────────────────────────────────────────────┐
│ 文档库 / 当前知识库名称                                      [进入知识库管理] │
│ 真实文件总数 · 已解析 · 已索引 · 待处理 · 异常  （仅展示已有真实统计）         │
├──────────────┬──────────────────────────────────────────┬─────────────────────┤
│ 资料范围     │ 当前范围：文献 / 肿瘤免疫                 │ 文档检查器          │
│              │ [AI 在资料中定位内容…________________]   │ 未选中：当前范围摘要 │
│ 全部文档  32 │ [解析状态] [索引状态] [证据可用]          │                     │
│              ├──────────────────────────────────────────┤                     │
│ 肿瘤免疫  12 │ □ 文档            解析    索引    更新时间 │ 选中后：             │
│ 心血管     8 │ □ ...                                     │ 文件名与完整来源路径 │
│ 待整理     5 │ □ ...                                     │ 真实状态/错误原因    │
│              │                                           │ 操作与详情入口       │
│ [管理资料]   │ Page 1 of 4                               │                     │
└──────────────┴──────────────────────────────────────────┴─────────────────────┘
```

推荐列宽：左侧 220px，中间自适应且不小于 640px，右侧 300px；列间使用 1px 分隔而非三张独立大卡片。

## 顶部范围条

位置：页面标题下、三栏工作台上。

包含：

- 面包屑式范围：`文档库 / 肿瘤免疫资料`。
- 当前来源的真实统计：文件总数、已解析、已索引、待处理、异常。若接口尚未提供某项，不展示该项，不能显示虚构的 0。
- 右侧仅有一个跨模块入口：`管理资料`，跳转知识库页，不提供上传按钮。

数字使用 `tabular-nums`，统计项不使用彩色大卡片。异常数仅在大于 0 时以危险色显示，已索引数可使用成功色，其余保持中性色。

## 左侧：资料范围导航

左栏是范围切换器，不是文件浏览器。

- 固定首项：`全部文档`，显示真实总数。
- 下方按知识库来源排列，每项显示名称、总文件数；异常大于 0 时在右侧显示小型红色数字。
- 当前选中项使用浅蓝背景和 2px 左侧主色标记，不使用厚重圆角大按钮。
- 空状态仅显示一句行动提示：`尚未导入资料。前往知识库选择资料文件夹。`
- 底部保留 `管理资料 →`，明确链接到知识库，不在这里创建来源或上传文件。

后续若实现真实子目录树，可在知识库项下按需展开；在没有真实目录数据前不渲染假的树状层级。

## 中间：资料定位与文档表格

### AI 资料定位条

AI 导航不应占用一个巨大聊天框。默认是 44px 的紧凑检索条：

```text
[定位]  在当前资料中找什么？例如：耐药机制、不良反应分级、PD-1 联合治疗  [开始定位]
```

- 默认继承左栏当前知识库范围；可展开切换到全部知识库。
- 可展开的二级选项：仅已索引、检索策略、条件验证说明。
- 提交后在表格上方显示结果区，不新开聊天页面。
- 结果必须显示来源知识库、相对路径、原文摘录、页码或章节（真实存在时）以及“打开文档详情”。
- 无结果时显示：`当前范围没有找到。可调整关键词、资料范围或索引状态。`

### 筛选工具条

AI 条下方为一行紧凑筛选器：

```text
[全部解析状态 ▾] [全部索引状态 ▾] [仅证据可用 □]                 [清除筛选]
```

- 筛选器使用描边控件，不用彩色胶囊。
- 有筛选条件时，在右侧显示 `已筛选 N 项`，其中 N 必须来自真实筛选状态。
- 不把“搜索文本”和“AI 资料定位”混为一件事：前者是文件名/状态筛选，后者是已解析原文导航。

### 文档表格

表格是页面核心，建议保留这些列：

| 列 | 规则 |
|---|---|
| 选择 | 用于批量操作，列宽固定。 |
| 文档 | 文件类型图标、文件名、知识库/相对路径的次级文字。 |
| 解析 | 真实状态点和状态文字。 |
| 索引 | 真实状态点和状态文字。 |
| 更新时间 | 使用等宽数字，按时间排序时显示方向。 |
| 操作 | 仅放当前状态允许的动作，例如开始解析、重试解析、重试索引、详情。 |

状态表现：

- 成功：绿色状态点与文字。
- 等待：灰色状态点与文字。
- 处理中：蓝色状态点与文字，可有低频呼吸动效；开启减少动态效果时静止。
- 失败：红色状态点与文字，错误只在右侧检查器展开完整内容。
- 过期：琥珀色状态点与文字。

不要给每个状态都加大面积彩色 pill。状态必须易扫读，但不应压过文档名称。

### 批量操作条

仅在选择至少一篇文档后出现于表格上方：

```text
已选择 3 篇  [建立索引]  [取消选择]
```

批量操作必须明确显示影响篇数；没有选择时不占用页面空间。

## 右侧：文档检查器

右栏是上下文检查器，不做成另一个列表。

未选中文档时：

- 显示当前资料范围名称。
- 显示真实文档总数及提示：`选择一篇文档，查看处理状态、来源和错误信息。`

选中文档后按以下顺序显示：

1. 文件名和类型。
2. 来源路径：`知识库 / 相对目录 / 文件名`。
3. 处理状态：解析、索引、证据可用性。
4. 若失败，显示真实错误原因和下一步可执行动作。
5. `打开文档详情`。

桌面端右栏常驻；小于 1100px 时变为表格行选中后的底部抽屉或页面内折叠区，不能直接消失导致用户无法查看失败原因。

## 操作与跳转规则

```text
知识库“查看文档” → /documents?sourceId=<id> → 左栏选中对应来源
文档库“管理资料” → /sources
AI 定位结果 → 对应文档详情，并携带真实文档 ID
文档详情面包屑“文档库” → 返回 /documents（可保留来源筛选时应保留 sourceId）
```

## 响应式规则

- ≥ 1100px：三栏工作台。
- 700px 至 1099px：左栏收窄为范围下拉，右侧检查器改为中间内容区下方的可展开面板。
- < 700px：范围切换改为横向滚动的来源条，AI 条与筛选器垂直堆叠，表格保持横向滚动，检查器作为底部抽屉。

## 组件调整建议

| 现有组件 | 设计调整 |
|---|---|
| `DocumentManager.vue` | 仅承担状态编排与范围切换，不堆叠大量展示细节。 |
| `DocumentFilters.vue` | 拆分文件筛选与 AI 资料定位，避免一个输入框承担两种搜索。 |
| `DocumentTable.vue` | 增加更清晰的状态点、等宽时间和行选中视觉。 |
| `DocumentNavigationPanel.vue` | 由大面板收敛成可展开的紧凑定位条。 |
| `DocumentNavigationResults.vue` | 作为表格上方的可追溯结果区，不与普通文件筛选混合。 |
| 新增 `DocumentInspector.vue` | 从 `DocumentManager.vue` 分离右侧检查器，保持组件单一职责。 |

## 验收标准

1. 文档库没有直接上传入口。
2. 用户一眼能看出当前资料范围和文档来自哪个知识库。
3. AI 定位与文件名/状态筛选明确区分。
4. 解析、索引、失败状态和可执行操作可在表格中快速扫描。
5. 选中一篇文件后，右侧检查器展示真实来源、状态、错误与详情入口。
6. 当前来源的统计只使用真实接口数据。
7. 窄屏仍能访问资料范围、表格筛选、文档检查器和详情入口。
8. 不引入装饰性大卡片、无意义图表、伪造统计或过度动画。
