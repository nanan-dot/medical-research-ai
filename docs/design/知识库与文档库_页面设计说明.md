# 文档与知识：知识库与文档库页面设计说明

## 1. 信息架构

```text
文档与知识
├─ 知识库：管理资料文件夹（知识源）
└─ 文档库：浏览、处理和检索文件夹内的具体文档
```

核心原则：用户添加的是一个文件夹，系统首先将其作为一个资料容器展示；不要把不同来源的全部文件直接平铺在同一个列表中。

## 2. 知识库页面

### 2.1 页面目标

让用户管理“哪些资料文件夹进入系统”，并快速判断每个文件夹是否同步正常、是否可用于检索。

### 2.2 推荐布局

```text
[页面标题：知识库]                                      [+ 添加资料文件夹]

[全部] [已启用] [异常] [最近同步]
────────────────────────────────────────────────────────────────────
资料文件夹卡片 / 列表
┌──────────────────────────────────────────────────────────────────┐
│ 肝癌免疫治疗资料                                                   │
│ H:\research\HCC-immunotherapy                                      │
│ 126 个文件 · 112 已索引 · 8 待处理 · 6 异常                         │
│ 上次同步：今天 14:32                                                 │
│ [同步] [查看文档] [更多操作]                                        │
└──────────────────────────────────────────────────────────────────┘
```

### 2.3 二级功能

#### 资料文件夹列表

- 一条记录代表一个知识源/资料文件夹。
- 显示名称、授权路径、类型、本次或最近同步时间。
- 展示聚合状态：文件总数、已解析、已索引、待处理、失败或异常数量。
- 默认优先显示异常文件夹与最近同步的文件夹。

#### 添加资料文件夹

- 以弹窗或右侧抽屉完成，避免将表单长期占用主内容区。
- 支持本地文件夹、Obsidian Vault、临时导入目录。
- 用户填写名称、来源类型与明确授权的本地路径。
- 提交前验证名称与路径；错误必须说明原因。

#### 同步与状态管理

- 支持手动同步、启用/停用、查看同步错误。
- 同步结果说明新增、修改、删除、跳过和失败文件数量。
- 资料文件夹只管理来源和整体状态；不在此页要求用户逐个处理文件。

#### 进入文档库

- 主操作为“查看文档”。
- 点击后跳转到文档库，并自动限定当前 `knowledgeSourceId`。
- 用户应该始终知道自己正在查看哪个资料文件夹。

## 3. 文档库页面

### 3.1 页面目标

让用户在某个资料文件夹中浏览具体文档、处理解析/索引问题，并用 AI 定位资料证据。

### 3.2 推荐布局

```text
[文档库]  肝癌免疫治疗资料 / 临床试验
────────────────────────────────────────────────────────────────────
左侧：资料目录树            中间：文档列表               右侧：文档详情/证据
- 全部资料                  [AI 查找资料……]             - 文档状态
- 肝癌免疫治疗              [仅已索引] [筛选]            - 解析摘要
  - 临床试验                ┌───────────────────────┐   - 命中页码/章节
  - 机制研究                │ 文件名 状态 更新时间   │   - 原文摘录
- 肺癌靶向治疗              │ IMbrave150.pdf 已索引  │
                             └───────────────────────┘
```

### 3.3 二级功能

#### 资料目录树

- 左侧保留知识源与子目录层级。
- 默认选中从知识库跳转进来的资料文件夹。
- 支持“全部资料”入口，但跨来源结果必须始终显示所属资料文件夹。
- 使用面包屑展示当前位置，例如：`文档库 / 肝癌免疫治疗资料 / 临床试验`。

#### 文档列表与筛选

- 中间区域仅显示当前目录下的文件；不将所有知识源中的文件平铺混合。
- 显示文件名、文件类型、解析状态、索引状态、更新时间、所属目录。
- 支持按文件名、解析状态、索引状态、可检索状态进行筛选。
- 支持批量建立索引与失败重试；批量操作需明确影响范围。

#### 文档导入与处理

- 支持单文件上传；资料文件夹中的文件通过知识库同步进入。
- 展示解析、索引、已变更、失败等真实状态。
- 失败时显示可理解的原因与下一步操作，例如重试解析、重试索引或检查原始文件。

#### AI 资料导航

- 放在文档列表顶部，作为“在资料中找什么”的入口，而不是通用聊天框。
- 默认搜索当前资料文件夹；可切换到全部知识源。
- 默认仅搜索已索引文档。
- 返回真实文档名、所属资料文件夹、相对路径、命中原因、页码/章节与原文摘录。
- 点击结果后自动切换到对应目录、选中文档，并在右侧定位到匹配证据。
- 无结果时明确显示“当前范围没有找到”；禁止编造医学资料、页码或结论。

#### 右侧详情与证据栏

- 桌面端作为常驻栏，移动端改为抽屉。
- 文档未选中时展示当前文件夹的状态摘要或使用提示。
- 文档选中后展示解析摘要、页码、章节、索引状态和错误原因。
- AI 命中时优先展示来源页码、章节和原文摘录，并提供“打开文档详情”。

## 4. 页面之间的关键跳转

```text
知识库“查看文档”
  → 文档库：限定到对应资料文件夹

文档库为空
  → 知识库：打开“添加资料文件夹”

AI 跨资料文件夹命中结果
  → 文档库：切换到对应资料文件夹与目录，并定位目标文档

文档解析/索引失败
  → 文档库：处理单个文件；知识库仅显示文件夹级异常数量
```

## 5. 设计边界

- 知识库页面负责“来源与资料文件夹”，不负责平铺处理每一个文件。
- 文档库页面负责“具体文件与证据”，不承担知识源的创建和同步配置。
- AI 只能检索用户已授权、已导入且具备相应处理状态的本地资料。
- 对无法由原文或元数据验证的条件，显示“未验证”或“语义相关”，不得标记为已满足。
