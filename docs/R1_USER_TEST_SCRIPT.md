# R1 真实用户试用脚本

## 准备

- 试用者：1 名未参与开发的研一用户；观察者只在用户明确求助时介入。
- 材料：5 篇公开或已授权、包含不同研究类型和至少一篇方法较复杂的真实医学论文。不得提交论文到 Git。
- 记录：开始/结束时间、每项是否独立完成、求助次数、阻塞/严重/一般错误；不录入姓名、邮箱或论文正文。

## 固定任务

1. 在模型设置中配置完全本地模型，测试连接。
2. 登记包含 5 篇论文的知识源并同步，确认 5 篇均登记；逐篇解析和索引。
3. 选择 1 篇生成结构化分析，核对样本量、方法、主要结果及至少一条页码来源。
4. 创建会话并连续提出 5 个问题；至少一个应当是论文无法回答的问题。
5. 点击每条引用，判断是否支持回答；记录数字、页码或证据错配。
6. 导出 Markdown，用本地编辑器打开，核对中文、引用、备注、时间和模型信息。
7. 对回答提交有帮助/需改进反馈，并填写四问反馈：有帮助吗、哪处错误、引用是否支持、下一步最想做什么。

## 错误恢复

分别模拟错误模型名、索引过期和不可写导出目录，确认提示可理解且可恢复。修复阻塞问题后由同一试用者从失败步骤重做。

## 完成率

固定任务共 7 项；`任务完成率 = 无观察者代操作完成项 / 7`。主观评价必须附至少一个具体观察或选择结构化真假项，否则不作为缺陷证据。
