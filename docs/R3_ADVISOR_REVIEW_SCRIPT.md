# R3导师场景测试脚本

## 目的
验证导师讨论报告是否足够支持真实讨论，并验证反馈记录不会被系统伪装为真实导师判断。

## 执行步骤
1. 选择一个已完成来源核对的研究方向和版本。
2. 导出导师讨论报告，逐项检查：证据、争议、风险、研究缺口、待确认项和报告生成时间。
3. 由真实导师或指定评审人阅读报告；若无法参与，记录“未参与”，不得生成替代意见。
4. 记录反馈原文摘要和反馈类型：接受 / 修改 / 拒绝 / 待补证据。
5. 对每条反馈绑定方向版本；不得覆盖旧反馈。
6. 修改候选方向或写作提纲，重新导出报告并比较版本差异。
7. 核对拒绝方向不能被直接当作已确认课题，候选仍需用户确认。

## 风险边界
- 系统输出是讨论材料，不是导师正式意见；
- 不保证创新性、可发表性或伦理批准；
- 不自动确定正式课题；
- 不自动投稿。

## 通过条件
- 报告可用于真实讨论；
- 风险、不确定性和缺证项明确；
- 反馈可追溯到方向版本；
- 没有伪造导师身份、意见或文献。
