## 真实交互

- 页面加载调用 `/api/v1/paper-research/center`；当前研究切换调用 current-context 接口；所有 loading/error/empty/partial failure 都有可操作状态。
- “继续阅读/继续精读”必须使用后端 `next_action.target`，回到准确论文、章节、reader session/page/offset；无能力时显示原因，不伪造按钮。
- “添加论文”调用现有 paper-library add 接口，成功后刷新中心并保留当前研究。
- 搜索防抖并拒绝过期响应；按 URL query 保存 q、current context、selected task，刷新/返回可恢复。
- 研究阶段、进度、活动、统计均为真实字段；不要在前端根据截图自行推导研究阶段或完成数。
- AI 不作为聊天面板；若 capability 为 unavailable，不显示可执行 AI 规划按钮。

## 响应式与无障碍

- 宽度不足时先将“当前研究”右侧阶段轨迹压缩，再将动态/最近论文纵向排列；移动端任务列表与详情分层，返回不丢失状态。
- 使用语义 heading、button、nav、main、section；图标按钮有 aria-label；状态有文字；焦点可见；键盘可从任务行进入详情和继续操作；保存/加载状态通过 aria-live。
- 尊重 `prefers-reduced-motion`，动画只用于 150–200ms 的状态过渡。
