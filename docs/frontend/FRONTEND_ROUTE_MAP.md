# 路由地图

| 路由 | 状态 | 页面 |

| `/` | MOCK | 工作台 |

| `/agent`、`/evaluation` | MOCK | R4 原型 |

`/documents/:id`、`/presentations/:id`、`/writing/:id` 为对应编辑/详情页。`/citation-check`、阅读计划等未接入路由显示 UNAVAILABLE。
