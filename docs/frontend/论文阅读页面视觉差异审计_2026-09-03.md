## 仍存视觉差异

1. 基准图的论文、进度、章节和记录数字来自另一份真实数据，未替换为静态示例；实际截图随当前 API 数据变化。
2. 右侧“实时翻译”按能力状态显示未启用面板，未复现基准图中的示例译文与术语数字。
3. 本轮首次运行曾因后端未启动出现 `ECONNREFUSED`；随后启动 FastAPI 服务后已完成真实 API E2E，8/8 通过并生成五视口 reader 截图。

| 优先级 | 区域 | 基准表现 | 当前差异与原因 | 修复方案 |
|---|---|---|---|---|
| P0 | 中间 PDF | 文献页面连续填充中间工作区 | 原先 PDF 容器受 `74vh` 限制，导致下方留白 | 移除固定最大高度，采用 flex 填充剩余高度 |
| P0 | 左栏 | 进度、结构切换、搜索位于上半部，收起按钮固定底部 | Grid 行定义会把结构区推向底部 | 改为纵向 flex，内容区 `flex:none`，收起按钮 `margin-top:auto` |
| P1 | 右栏记录卡 | 白色独立卡片、四项横向统计、图标+数字 | 当前统计无彩色图标，字号和间距偏紧 | 保持真实统计 API，补充语义图标色块、卡片内边距和统计列间距 |
| P1 | 右栏辅助面板 | 面板与记录卡有明确间距，Tab 下划线清晰 | 当前 Copilot/翻译区域高度随内容变化，视觉密度偏高 | 固定面板最小高度，统一 Tab 高度与边框层级 |
| P1 | 顶栏/三栏 | 顶栏、左/中/右栏边界清晰 | 旧全局壳层曾叠加在阅读页外部 | 阅读路由隐藏全局侧栏/顶栏，保留专属 Header |
| P2 | 响应式 | 窄屏可打开阅读导航 | 左栏展开时会遮挡右侧交互 | 移动端使用显式开关并在验证中关闭遮罩后继续操作 |

## 数据与降级检查

- PDF 使用真实 `reader bootstrap` 返回的 `content_url`，不使用静态截图或假图片。
- 翻译能力由 bootstrap 的 `capabilities.translation` 控制；服务不可用时显示保留态，不伪造译文。
- anchor/章节资产未就绪时显示受控降级提示，PDF 原文仍正常加载。
