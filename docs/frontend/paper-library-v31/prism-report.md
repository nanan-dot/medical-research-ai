# 论文库 V3.1 Prism 全量复核

## Generated Pipeline

### Pass 1 — 契约—状态守恒

逐项从 `PaperLibraryView`、`usePaperLibrary`、`usePaperOverview` 及 API 类型反推用户所见状态。为每个列表字段、筛选值、入口按钮和概览字段建立“后端来源 → 前端投影 → 用户动作”的链，并构造一条无全文、无分析、无研究关联的真实记录和一条可阅读、可分析的理想记录。诊断任何被前端推测、被静态文案替代或因响应顺序改变的状态；写出只允许后端决定的事实。

### Pass 2 — 写入路径与失败反演

以上一轮的状态链为输入，分别执行“添加 DOI/PMID、从资料库选择、上传 PDF、刷新元数据、修改研究关联、复制标识符”的反向失败演练。为每条路径构造超时、409 版本冲突、无 document_id、上传无文档 ID、剪贴板权限拒绝五种输入，检查 UI 是否给出真实可恢复反馈、是否误导航、是否留下未处理 Promise。把通过和未通过的边界归因到组件单一职责或调用端。

### Pass 3 — 布局断点与可达性压力

以上两轮发现为输入，在 1536、1280、1024、768、390 五个真实 API 截图中量取壳层、筛选、列表、概览的空间约束；再以键盘方向键、Enter、Escape、焦点进入弹窗、关闭抽屉进行行为压力。构造“1024 保留列表而筛选变抽屉”和“390 概览不得永久抢占列表”两个反例，识别布局规则是否将主任务隐藏或使焦点不可恢复。

## Pass 1 — 契约—状态守恒结果

- 六组筛选都以重复 query 参数发送；服务端承担组内 OR、组间 AND。
- 行操作严格消费 `preferred_work_action`、`reading_entry`、`analysis_entry`，而非根据状态字符串猜测；不可用操作会禁用并显示服务端原因。
- 列表与概览分别调用 `/items` 和 `/overview`；概览请求有 AbortController 与序列号，旧响应不会覆盖新选择。
- 分析进度仅在 `analysis_progress` 存在时展示 `完成数 / 总数`；未知进度显示实际分析状态。

## Pass 2 — 写入路径与失败反演结果

- DOI/PMID 和资料库选择均直接调用 `POST /paper-library/items`；PDF 上传复用资料库导入，成功后只使用返回的真实 `document_id`。
- 上传后加入论文库使用 `Promise.allSettled`；刷新列表异常有用户可见提示，不会留下未捕获异步失败。
- 研究关联 PUT/DELETE 传递 `expected_version`，409 明确提示刷新后重试。
- 剪贴板权限失败现在会显示“无法访问剪贴板，请手动复制”。
- 发现：概览底部此前在推荐操作为阅读时重复“阅读”而缺少分析入口；已改为始终展示推荐操作与另一项工作入口。

## Pass 3 — 布局断点与可达性压力结果

- 1536 采用 196 / 766 / 368 列宽，右侧 14px 留白与参考锚点一致。
- 1280 保持筛选、列表、概览三栏；1024 修正为“筛选抽屉 + 列表 + 300px 概览”，不会再由概览挤掉列表。
- 768 与 390 使用列表主画面；筛选和概览均为可关闭抽屉。Playwright 已覆盖筛选抽屉、概览抽屉、方向键和 Enter 语义。

## Adversarial Pass

- “所有写操作都已端到端验证”不能成立：Playwright 为避免在隔离库中触发元数据联网或制造持久样例，只覆盖了可安全读取的筛选/菜单/抽屉操作。新增、上传、刷新元数据、关系写入已有真实 API 调用和单元契约，但本轮未做外部 PubMed 写入验收。
- “1536 像素差异达到 3%”不能成立：未遮罩的真实数据全页差异是 15.07%。参考图中的行是有全文、有阅读/分析/关联记录的样例，而隔离库中的 5 条均是只有 PMID 的元数据论文；这个数值不能单独代表 CSS 偏差。
- “全局导航已复刻”不在本任务授权范围内，且未修改。论文库专属区域已锚定，壳层仍服从现有 `AppShell`。

## Final Findings

**Conservation law**：论文库只投影后端论文工作状态并提供已有阅读/分析页入口；资料处理、PDF/OCR 与分析执行本身不在论文库前端重建。

**Retracted claims**：没有宣称所有写操作或 3% 全图视觉差异已通过。

| 结论 | 位置 | 严重性 | 处理状态 |
|---|---|---:|---|
| 1024 宽度曾隐藏主列表 | `PaperLibraryView.vue` 断点 | 高 | 已修复并重新截图 |
| 概览曾缺少非主操作入口 | `PaperOverview.vue` footer | 中 | 已修复 |
| 剪贴板拒绝会造成静默失败 | `PaperOverview.vue` | 低 | 已修复 |
| 全页视觉差异受真实数据和壳层影响 | 视觉验收 | 中 | 如实保留，未伪造 3% 结论 |

**Deepest finding**：视觉参考中的“丰富工作状态”并不是可由 CSS 弥补的差异。若要完成有意义的 3% 数据区视觉对比，必须在隔离数据库中建立与参考图同等状态的真实论文、全文、阅读、分析和研究关联夹具，而不是用前端 Mock 替代 LIVE API。
