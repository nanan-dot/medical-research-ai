# A0 验收条件（来源：A0 设计第 1–15 节及共享锚点设计）

每行均为 Given / When / Then；测试归属在最终追踪报告记录。

| ID | Given | When | Then |
|---|---|---|---|
| AC01 | 受控有效 PDF | 提交/提取 | 文件路径、签名、哈希校验；独立锁版 PDF.js，无不兼容回退 |
| AC02 | 工具缺失或版本不兼容 | 提交/健康探测 | 503/UNAVAILABLE，安全错误，不创建假成功 |
| AC03 | 合法流 | 逐行读取 | 即时核对 header；连续 item/source/page 索引，受限 styles、有限坐标和合法 Unicode |
| AC04 | 重复/跳页/超行/缺 trailer/哈希篡改 | 校验 | 即使 exit0 仍失败，不发布 |
| AC05 | 数字/Unicode 黄金向量与同 PDF | Node/Python、多次运行 | 相同 canonical/page/document 哈希；配置版本改变请求身份 |
| AC06 | 组合字符、emoji、空白、软连字符、控制字符 | NFC/页连接 | 原值保留，UTF16 映射、synthetic 连接、前项 EOL/间距/方向规则，不合断词 |
| AC07 | 空白/扫描/混合/旋转/表格页 | 提取 | 全套技术质量指标，空页不凭空断言扫描，待复核门禁 |
| AC08 | 相同请求、并发请求/worker | 执行 | 单一草稿/活动任务/当前版本，租约 fencing、进度≤95直到发布 |
| AC09 | 崩溃/失败/取消/过期租约 | 重试或终止 | 无部分发布、释放进程和临时文件，有限重试，失败不能假成功 |
| AC10 | 完整/新版本/强制诊断 | 原子发布 | 旧版本保留，新版本替代；诊断比较不重复内容身份 |
| AC11 | 文件执行时变化 | 最终校验/manifest | 拒绝旧版本发布/返回为当前 |
| AC12 | 查询接口、错误文档/页 | 请求 | 正确状态码，按文档/源授权，限量批次，不泄漏部分数据 |
| AC13 | 恶意文件名、动作/附件、损坏/加密 PDF | 提取 | 不执行动作/网络，错误分类安全，资源硬限额和进程树回收 |
| AC14 | 旧数据库/新数据库 | upgrade/downgrade/upgrade | schema 可往返，现有数据和约束保留 |
| AC15 | 授权真实论文、多平台环境 | 黄金回归 | 符号、布局、文本索引可复现；未实测不冒称通过 |

完成门禁包含专项与仓库回归、lint、typecheck、构建。技术 ready 不代表医学专家审核。
