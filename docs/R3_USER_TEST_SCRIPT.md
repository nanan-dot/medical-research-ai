# R3真实用户场景测试脚本

## 目的
验证从真实研究主题到证据矩阵、候选方向、导师报告、提纲和写作项目的连续流程。该脚本不自动确定正式课题，不要求调用云端模型。

## 执行前记录
- 执行人：
- 日期：
- 主题原文（不得编造，填写用户真实主题）：
- 使用的证据矩阵版本：
- 数据是否包含未发表材料：是 / 否

## 步骤
1. 录入真实主题，并确认原始主题不可被结构化结果覆盖。
2. 建立或选择证据矩阵，逐条检查 PMID/DOI 是否来自检索结果；记录矩阵版本、检索日期和文献数量。
3. 生成候选方向，检查至少 3 个候选、来源绑定和跨主题/缺口依据。
4. 将候选标记为“待确认”，不得把候选标题当成正式课题。
5. 导出导师讨论报告，核对证据、争议、风险、缺口和待确认项。
6. 记录导师意见；若导师无法参与，使用“未获得真实导师意见”标记，禁止伪造导师身份或判断。
7. 生成组会/开题提纲，核对每节来源或显式缺证标记。
8. 创建写作项目，确认材料、草稿、引用、待确认项和版本可编辑。
9. 导出 Markdown，检查来源标记、风险提示和待确认项仍然存在。
10. 修改一处内容并恢复历史版本，确认旧版本未被覆盖。

## 通过条件
- 每条文献性陈述都能回到真实来源；
- 风险和不确定性可见；
- 候选未被自动升级为正式课题；
- 写作内容可人工修改和恢复；
- 无虚假数据、引用、导师意见或投稿保证。
