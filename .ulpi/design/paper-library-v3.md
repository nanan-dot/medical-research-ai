# 论文库 V3 冻结设计规格

## 冻结声明

本文件冻结论文库 V3 的产品边界、信息架构、交互语义、数据关系、响应式行为和验收标准。后续实现不得重新解释这些决策。功能变化必须先更新本规格并记录原因。

Every screen must read as the same product if placed side by side.

论文阅读页和论文分析页不在本次设计范围内。论文库只提供进入现有页面的入口，不复制或重构其能力。

## Design Read

安静而高密度的科研论文控制台：用户在一屏内判断论文是什么、工作进行到哪里、服务于哪些研究，并立即继续工作。

### 视觉方向

- 继承 `DESIGN.md` 的 `technical / utilitarian` 方向。
- 视觉密度为 8，信息密集但不拥挤。
- 主要使用分割线、稳定列宽和层级文字，不使用卡片墙或嵌套卡片。
- 产品标志性元素继续使用“证据路径线”，仅表达当前选中论文及其研究关系。
- 页面只有一个固定主操作：`添加论文`。
- 不在 Header 放置泛化的 `AI 论文助手`。

## 产品边界

### 论文库负责

- 查找和筛选论文；
- 展示阅读状态与阅读进度；
- 展示论文分析状态与完成进度；
- 管理论文与研究之间的关联；
- 管理每一条论文研究关系中的研究角色；
- 进入现有论文阅读页；
- 进入现有论文分析页；
- 跳转到对应资料记录；
- 从资料库选择论文或添加新论文。

### 论文库不负责

- PDF 解析、OCR、索引和附件管理；
- 资料来源配置和处理任务管理；
- 论文阅读功能本身；
- 论文分析功能本身；
- 独立论文详情页；
- 泛化 AI 对话入口。

资料状态仅在阻断论文工作时显示轻量异常：`资料处理中`或`全文不可用`。点击异常进入对应资料记录。

## 导航与命名

研究资源下固定为：

```text
研究资源
├── 论文库
├── 资料库
└── 笔记库
```

- 页面名称：`论文库`
- 默认内部视图：`全部论文`
- 页面副标题：`管理用于阅读、分析与研究工作的论文`
- 主按钮：`添加论文`
- 推荐路由：`/papers`

## 桌面信息架构

```text
论文库 Header
├── 标题与说明
├── 全局论文搜索
└── 添加论文

快捷视图
└── 全部论文 / 最近使用 / 阅读中 / 分析中 / 待归类

工作区
├── 左侧筛选栏
├── 中间论文列表
└── 右侧论文概览
```

三种布局家族必须同时存在：顶部工具栏、快捷视图条带、三栏工作区。工作区内部使用分割列表和侧栏，不嵌套卡片。

### 尺寸规则

- `>= 1440px`：筛选栏 224px，论文概览 336px，中间列表使用剩余宽度。
- `1280px 至 1439px`：筛选栏 208px，论文概览 312px。
- `1024px 至 1279px`：筛选栏变为可关闭抽屉；概览保留 300px。
- `768px 至 1023px`：列表占满；筛选和概览分别使用抽屉。
- `< 768px`：单列列表；快捷视图横向滚动；筛选为全屏面板；概览为底部抽屉。
- 页面不得产生横向溢出，移动端触控目标至少 44px。

## 快捷视图语义

快捷视图是可组合的预设筛选器，不是互斥生命周期。

| 视图 | 计算规则 |
|---|---|
| 全部论文 | 当前用户论文库中的全部论文 |
| 最近使用 | 按最近阅读或分析活动排序，默认统计近 30 天有活动的论文 |
| 阅读中 | 阅读状态为 reading |
| 分析中 | 分析任务已开始且未完成 |
| 待归类 | 未关联任何研究，或至少一条研究关系未设置研究角色 |

`待归类`必须由关系数据计算，不能保存为人工维护的论文状态。

每个快捷视图显示真实计数。服务端无法提供计数时显示文字而不伪造数字。

## 左侧筛选栏

固定为六组，禁止继续添加资料库维度：

1. 阅读状态：默认展开；未阅读、阅读中、已阅读。
2. 论文分析：默认展开；未分析、分析中、已分析。
3. 研究角色：默认展开；核心证据、背景支持、方法参考、补充阅读、待评估。
4. 论文类型：默认折叠；RCT、Meta-analysis、Systematic Review、Guideline、Cohort 等真实值。
5. 关联研究：默认折叠，支持组内搜索；包含未关联研究。
6. 标签：默认折叠，支持组内搜索。

筛选规则：

- 组内多选为 OR，组间组合为 AND。
- 已选条件在列表顶部显示为可移除 chips，例如 `阅读中 ×`。
- 提供 `清除全部`，仅在存在筛选时显示。
- 筛选状态写入 URL，刷新、分享、前进和后退均能恢复。
- 不显示 PDF 解析状态、OCR、资料来源或 AI 处理状态筛选。

## 中间论文列表

### 列表工具行

- 左侧显示真实结果数，例如 `328 篇论文`。
- 右侧提供单一排序控件，默认 `最近活动`。
- 排序项固定为：最近活动、添加时间、发表年份、标题。
- 已选筛选 chips 位于结果数上方或同一工具区域，根据宽度换行。

### 论文工作卡片

每条论文固定四层语义，但通过字号、间距和分割线降低视觉重量。

#### 第一层：身份

- 多选框；
- PDF 缩略图或统一论文占位图；
- 论文标题，最多两行；
- 阻断性资料异常，仅异常时显示。

#### 第二层：书目信息

显示：`首位作者 et al. · 期刊 · 年份`。

列表不显示卷、期、页码。完整引文只在右侧论文概览中显示。

#### 第三层：论文属性

- 研究设计类型，例如 RCT；
- 期刊分区，例如 Q1；
- 属性标签和研究角色在视觉与数据上保持分组，不得混排。

#### 第四层：科研工作状态

- 阅读：未阅读、阅读中、已阅读；阅读中显示章节和百分比。
- 论文分析：未分析、分析中、已分析；分析中显示完成数，例如 `8 / 12`。
- 关联研究与角色：显示一条主要关系；多条时显示 `另有 N 个研究`。
- 最近工作：仅显示一条简短时间或动作线索。

### 行高和溢出

- 桌面目标行高 132 至 148px，同一状态下保持稳定。
- 标题最多两行，作者和期刊一行省略。
- 路径不在论文卡片常态展示。
- 研究名称一行省略，完整内容使用 `title` 或可访问描述。
- 异常信息占用预留区域，不造成其他列错位。

### 操作权重

- 最近有效行为为阅读：`继续阅读`为主按钮，`继续分析`为次级文字入口。
- 最近有效行为为分析：`继续分析`为主按钮，`继续阅读`为次级文字入口。
- 阅读和分析均未开始：显示主按钮 `开始阅读`，次入口 `开始分析 →`。
- 次级入口不得依赖 hover 才可发现。hover 只能增强，不得作为唯一可达方式。
- 低频操作进入 `···` 菜单。
- 不显示 `查看详情`。

### 选择与导航

- 单击卡片空白区域：选中论文并更新右侧概览，不导航。
- 单击论文标题：直接进入现有论文阅读页。
- 单击阅读按钮：进入现有阅读页并恢复上次位置。
- 单击分析按钮：进入现有论文分析页。
- `ArrowUp`和`ArrowDown`：在列表中移动当前选中论文。
- `Enter`：打开当前选中论文的阅读页。
- 键盘切换后，选中项滚动进入可见区域。
- 不使用双击作为任何主要交互。

## 右侧论文概览

论文概览是当前选中论文的快速工作上下文，不是详情页。

### 默认行为

- 桌面首次载入且列表非空时，默认选中第一篇。
- 翻页后默认选中新页第一篇。
- 如果刷新后 URL 指定的论文仍在结果中，恢复该论文。
- 用户主动关闭概览后，右栏消失，中间列表扩宽。
- 用户再次选择论文或点击“打开概览”时恢复右栏。
- 列表为空时，概览不占据空白区域。

### 内容严格限定为四块

1. 基础信息：标题、作者、期刊、年份、完整引文、DOI、PMID、论文类型、期刊分区。
2. 论文工作：阅读百分比与当前位置；论文分析完成数。
3. 关联研究：研究名称和该关系中的研究角色。
4. 最近工作：最多三条真实活动记录。

禁止加入摘要全文、Claim 数量、Evidence 数量、引用次数、附件列表、解析详情或 AI 摘要。

### 底部操作

- 主操作随最近上下文显示 `继续阅读`或`继续分析`。
- 另一工作入口为次级文字按钮。
- `查看对应资料`为三级链接。

## 添加论文流程

点击 `添加论文`打开轻量菜单：

```text
从资料库选择
从现有论文资料中加入论文库

导入新论文
上传 PDF、输入 DOI 或 PMID
```

### 幂等规则

- DOI、PMID和已解析 PDF 标识用于匹配已有论文。
- 匹配已有论文时不得创建重复 Paper。
- 已存在且全文可用：提示 `已在论文库`，提供 `查看论文`。
- 已存在但缺少全文：提供 `补充全文`。
- 新 PDF 匹配已有论文：关联为资料或全文版本，不创建重复论文。
- 匹配不确定时要求用户确认，不进行模糊静默合并。
- 添加过程的复杂状态留在添加流程，不进入论文库首页。

## 数据模型冻结

研究角色属于论文和研究之间的关系，不属于论文全局属性。

```text
Paper
├── identity: PMID / DOI / canonical metadata
├── document links
├── reading state
└── analysis state

Research
└── research workspace identity

PaperResearchRelation
├── paper_id
├── research_id
├── role
├── added_at
└── note (optional)
```

关系约束：

- `(paper_id, research_id)`唯一；
- `role`固定枚举：core_evidence、background_support、method_reference、supplementary_reading、to_evaluate；
- 同一论文可在不同研究中承担不同角色；
- 删除一条关系不得删除 Paper；
- `待归类`根据关系缺失或 role 缺失计算；
- 查询“某研究的核心证据”必须基于关系表过滤。

## 页面状态

| 状态 | 展示与行为 |
|---|---|
| 初次加载 | 快捷视图、筛选和列表使用结构化骨架；不显示假数据 |
| 筛选加载 | 保留当前内容，列表区域显示忙碌状态，防止布局跳动 |
| 空论文库 | 说明论文可从资料库或 DOI/PMID 添加，主操作为添加论文 |
| 无筛选结果 | 保留筛选 chips，提示调整条件并提供清除筛选 |
| 部分数据失败 | 可用区域继续展示；失败模块独立重试 |
| 整页失败 | 说明加载失败并提供重试，不清空 URL 筛选 |
| 离线 | 保留已加载内容为只读，禁用写操作并说明网络状态 |
| 资料处理中 | 卡片轻量提示，可跳转资料库；阅读入口按真实可用性决定 |
| 全文不可用 | 允许查看元数据和研究关系；阅读按钮显示不可用原因 |
| 慢请求 | 300ms 后显示加载反馈，避免瞬时闪烁 |

## 主要用户流程

### Flow A：查找并继续论文工作

```text
进入论文库
→ 恢复 URL 筛选和排序
→ 默认选中首篇或 URL 指定论文
→ 搜索、筛选或键盘切换
→ 查看右侧工作上下文
→ 继续阅读或继续分析
→ 进入既有页面
```

返回论文库时恢复筛选、页码、排序、选中论文和概览开关状态。

### Flow B：管理研究关系

```text
选择论文
→ 在概览或更多菜单选择管理关联研究
→ 选择研究
→ 为每条关系设置研究角色
→ 保存
→ 卡片、筛选计数和待归类视图同步刷新
```

并发修改时以后端最新版本为准，冲突必须提示并重新加载关系，不能静默覆盖。

### Flow C：添加论文

```text
添加论文
├── 从资料库选择 → 匹配论文身份 → 创建或关联
└── 导入新论文 → PDF / DOI / PMID → 身份匹配 → 创建或补充全文
```

成功后选中新添加或已存在论文并更新概览。失败保留输入并提供重试。

## URL 状态

应支持以下语义，具体命名可按现有路由规范调整但不得损失状态：

```text
view
query
reading_status
analysis_status
research_roles
paper_types
research_ids
tags
sort
page
paper_id
overview
```

数组参数必须可完整往返，不得只保存第一项。浏览器前进和后退必须恢复相同视图。

## 组件边界

| 组件 | 单一职责 | 输入 | 输出 |
|---|---|---|---|
| PaperLibraryView | 路由级组合和 URL 协调 | route | 状态变更与导航 |
| PaperLibraryHeader | 标题、搜索和添加入口 | query、loading | search、add |
| PaperQuickViews | 预设筛选与真实计数 | counts、active | select |
| PaperFilterRail | 分组筛选与折叠状态 | facets、filters | change、clear |
| ActiveFilterChips | 已选条件概览 | filters | remove、clear |
| PaperWorkList | 列表、选择与键盘导航 | items、selectedId | select、open、paginate |
| PaperWorkCard | 单篇论文四层信息及操作 | paper、workState | select、read、analyze、menu |
| PaperOverview | 当前论文快速上下文 | paper、relations、activity | read、analyze、viewResource、close |
| AddPaperMenu | 两种添加路径选择 | open | selectSource、importNew |
| ManageResearchRelations | 论文研究关系编辑 | paperId、relations | save、cancel |
| usePaperLibrary | 查询、分页、取消和状态协调 | URL filters | page、facets、counts、error |

所有 props 和 emits 必须使用 TypeScript 明确定义。路由 View 保持薄层，数据副作用放入 composable，展示组件遵循 props down、events up。

## 无障碍冻结规则

- 页面必须有唯一 `h1`：论文库。
- 快捷视图使用可访问的 tabs 或命名导航语义，并明确当前项。
- 筛选折叠项暴露 `aria-expanded`和控制目标。
- 筛选结果变化使用礼貌型 live region 宣布结果数。
- 论文列表使用可访问列表语义；当前选中项同时有视觉与 `aria-selected`表达。
- 卡片标题为真实链接，支持复制链接和浏览器常规行为。
- 上下键快捷导航只在列表获得焦点时生效，不劫持页面滚动或输入框。
- Drawer 和 Dialog 必须约束焦点、支持 Escape、关闭后恢复焦点。
- 所有状态同时使用文字或图标，不只依赖颜色。
- 焦点环使用锁定的 2px accent 和 2px offset。
- 动效仅用于抽屉和选中态过渡；尊重 `prefers-reduced-motion`。

## 性能约束

- 搜索输入防抖 200 至 300ms，并取消过期请求。
- 切换筛选和翻页时保留布局，避免整页闪烁。
- 初期使用服务端分页；列表超过实际性能阈值后再评估虚拟化。
- 概览的活动记录和关系可按选中论文延迟加载，但必须防止旧请求覆盖新选择。
- 快捷视图计数应由聚合接口返回，不能遍历当前页推算全量计数。

## 明确禁止的实现

- 将论文库直接复用为资料库文件列表；
- 将研究角色保存为 `paper.role`；
- 使用人工 `待归类`状态字段；
- 把检索结果临时 saved 标记当作正式论文库记录；
- 在列表加入卷期页码、摘要全文或处理任务详情；
- 通过双击打开论文；
- 仅在 hover 时提供开始分析入口；
- 在 Header 放置泛化 AI 助手；
- 伪造论文、DOI、PMID、计数、进度或活动记录。

## 验收标准

- [ ] `/papers`展示论文库，默认视图为全部论文。
- [ ] 论文库与资料库、阅读页、分析页的数据和职责明确分离。
- [ ] 五个快捷视图符合冻结计算语义，待归类为派生状态。
- [ ] 六组筛选遵守默认展开策略，支持组合、chips、清除和 URL 往返。
- [ ] 论文卡片固定四层结构，不显示卷期页码，不混排论文属性和研究角色。
- [ ] 单击卡片选择，单击标题打开阅读页，不存在双击主交互。
- [ ] 主次工作入口根据最近上下文调整，两个入口始终可达。
- [ ] 键盘上下键切换，Enter 打开，焦点与滚动行为正确。
- [ ] 桌面默认选中第一篇；翻页默认选中新页第一篇；概览可关闭并释放宽度。
- [ ] 概览严格限制为四块，最近活动最多三条。
- [ ] 添加论文幂等，能够处理已存在论文和补充全文，不静默重复创建。
