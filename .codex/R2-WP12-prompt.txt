【本任务目标】
R2-WP12：证据矩阵

负责模块：证据矩阵

【来源需求】
### 目标

形成可用于综述、开题和方向分析的结构化文献表。

### 数据

- 文献；
- 比较字段；
- 用户备注；
- 课题相关度；
- 阅读状态；
- 文献状态；
- 证据来源；
- 生成版本。

### 功能

- 创建矩阵；
- 增删论文；
- 修改字段；
- 编辑结果；
- 导出 Markdown / CSV；
- 后续写回 Obsidian。

### 验收

- 用户可创建真实矩阵；
- 数据不会因重新生成全部丢失；
- 人工修改与模型生成可区分。

- CRUD /evidence-matrices

- POST /evidence-matrices/{id}/export

【数据与状态要求】
- matrix
- matrix_documents
- matrix_fields
- matrix_cells
- user_notes
- source_type
- version

【实施步骤】
1. 设计规范化或混合存储
2. 支持字段管理
3. 增删论文
4. 复用比较结果
5. 区分生成与人工值
6. 版本化
7. 导出Markdown和CSV

- JSON字段后期难迁移
- 删除字段丢数据
- 多人不在范围
- CSV转义

【测试要求】
- CRUD
- 字段新增删除
- 论文增删
- 人工备注
- 版本
- 导出
- 重新生成

- 普通单元测试不得依赖真实云端费用；
- 外部服务使用 Mock；
- 真实集成测试单独标记；
- 实际运行测试，禁止声称未运行的测试通过；
- 数据库模型变化必须生成并审查 Alembic 迁移；
- 前端任务必须运行类型检查、测试和生产构建；
- 不得在测试、日志和响应中泄露 API Key、未发表材料或完整敏感内容。

【阶段禁止范围】

- 完整写作系统

- 自动Meta分析
- 绕过付费墙
- 多用户和机构部署

【通用禁止】
- 不进行与本任务无关的重构；
- 不把所有逻辑写进 main.py；

- Repository 不调用大模型；
- Agent 不直接操作数据库；

- 不硬编码密钥；
- 不伪造论文、DOI、PMID、页码、引用、医学结论或测试结果；
