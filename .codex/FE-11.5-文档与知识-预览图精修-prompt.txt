## 精修要点（对照 V1 的缺陷）

### 1. 内容区收窄 + 留白呼吸感
- 主内容区最大宽度约 **1280px**，居中，`margin: 0 auto`，左右留白稳定。
- 页面垂直留白加大：主内容 `padding: 10px 36px 48px`；面板与筛选条间距 20-24px；来源行内 padding 18-20px 垂直。
- 段落/区块间距参照"摄影网站留白"：不贴边、不顶天立地。

### 2. 低语边框（whisper border）
- 面板/行/输入框边框统一为 `1px solid rgba(16,33,61,.08)`（whisper）或 `.12`（soft）。
- 阴影近乎不可见：`0 1px 2px rgba(16,33,61,.04), 0 4px 16px rgba(16,33,61,.03)`。
- 禁止大面积投影、禁止重边框。

### 3. 来源行"安静行"主次分层（知识库）
- 左侧：类型图标（36px 圆角方块，accent-soft 底）+ 名称（15px/700）+ 路径（12.5px 等宽字体 muted）+ 类型标签（小 pill）。
- 中部：聚合统计行（数字 strong + 标签 muted，间距 16px）；异常数字红色。
- 右侧：上次同步时间（12px muted）+ 状态 pill（成功绿/等待灰/错误红，圆角 999px 轻底）+ 错误文案（红色 12px）。
- 操作区：同步（ghost 按钮）、开关（语义化 switch）、查看文档（钴蓝 link 带 →）、⋮（kebab）。
- 行 hover：极浅蓝 `#FAFCFF`；行间 `border-top: 1px solid rgba(16,33,61,.08)`。

### 4. 顶栏品牌化
- 面包屑：`文档与知识 / [项目名 ▾]`（项目名做成轻量 pill 带下拉箭头）。
- 搜索框：白底、低语边框、`⌕ 搜索与跳转` + `Ctrl K` kbd。
- 右侧：任务图标（32px 圆角方块）+ 头像（30px 圆形钴蓝底白字）。
- 侧栏：品牌标识（素问 + 副标题）+ 研究空间分组 + 底部（后台任务/设置）；当前项 accent-soft 底 + accent 字。

### 5. 状态 pill 轻量化（文档库表格）
- 解析/索引状态改为小 pill：成功（success-soft 底 success 字）、失败（danger-soft 底 danger 字）、等待（灰底灰字）、过期（warn-soft 底 warn 字）。
- pill 内保留状态点或图标 + 文字双表达。

### 6. 视觉系统（沿用 V2 样板，两页统一）
- 画布 `#F6F8FB`；内容面白色；标题深海军蓝 `#10213D`；辅助 `#667995`；主强调钴蓝 `#2563EB`。
- 成功 `#1B8A5A` / 警告 `#B7791F` / 错误 `#C62828`，各带 soft 底色。
- 圆角：按钮/输入 8px，面板 12px；状态 pill 999px。
- 字体系统无衬线栈；H1 33px/750，H2 17px/700，正文 14px，元信息 12-13px。
- 禁止：紫色渐变、玻璃拟态、霓虹、暖米色、青绿主题、营销 Hero、插画。
