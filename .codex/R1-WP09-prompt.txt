【本任务目标】
R1-WP09：模型设置与隐私提示

负责模块：模型设置与隐私提示

【来源需求】
### 目标

让真实用户自行配置云端或本地模型。

### 页面与功能

- 云端/本地模式；
- Provider；
- API Base；
- API Key；
- Model Name；
- 测试连接；
- 默认模型；
- 云端内容授权；
- 密钥掩码；
- 删除配置。

### 规则

- 密钥不回显；
- 本地失败不自动切云端；
- 混合模式显示数据外发提示；
- 完全本地模式清晰标识。

### 验收

- 用户可保存配置；
- 连接测试准确；
- 错误信息可理解；
- 密钥不泄露。
