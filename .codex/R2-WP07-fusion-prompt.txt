【本任务目标】
R2-WP07：保存论文与知识库衔接——把检索结果收藏进本地知识库，支持绑定本地 PDF，全程遵守版权边界。

【来源需求】
### 功能
- 收藏元数据；
- 加入本地知识库；
- 关联已有 PDF；
- 手动选择全文；
- 记录全文状态；
- 不绕过付费墙；
- 不自动下载无权限内容。

### 全文状态（enum）
```text
metadata_only
local_pdf_available
open_access_available
unavailable
```

### 验收
- 元数据可以先保存；
- 后续可绑定本地 PDF；
- 已有文档可匹配 DOI 或 PMID。

【与 skills 的融合点（必须体现）】
1. **fulltext-retrieval 版权边界**（核心融合点）：保存论文时**只记录全文状态，不自动下载**。
   - `open_access_available` 表示该 DOI/PMID 有已知 OA 来源（如 PMC），但**是否下载由用户显式触发**，本 WP 不做自动抓取；
   - 状态判定基于已有数据（PMC id 存在性等可验证信号），禁止伪造"可获取"；
   - 明确"不绕过付费墙"：付费内容一律 `unavailable` 或 `metadata_only`，绝不尝试破解。
2. **manage-refs 收藏衔接**：`literature_search_item_state.saved` 是"临时收藏"，
   本 WP 的"保存到知识库"是**正式收藏**（library_item），两者语义不同——文档注释必须说清区别；
   WP06 去重后的 canonical 记录可作为保存入口之一（保留 source_search_id 溯源）。
3. **状态可解释（反幻觉延伸）**：library_item 响应携带 `fulltext_status_reason`（如
   "PMC ID available" / "no open access source"），前端展示，禁止凭空声称有全文。

【建议文件范围】
- app/modules/library_item/model.py（library_item 表：pmid/doi/document_id/source_search_id/fulltext_status）
- schema.py（LibraryItemCreate/Read/FulltextStatus）

【接口要求】
- POST /literature-results/{id}/save（从检索结果保存为 library_item）
- POST /library-items/{id}/link-local-pdf（绑定本地 PDF，含解绑）
- GET /library-items（列表，分页 + 按状态筛选）

【数据与状态要求】
- fulltext_status：metadata_only / local_pdf_available / open_access_available / unavailable
- fulltext_status_reason：状态判定的人类可读理由
- pmid / doi / document_id / source_search_id
- 防重复收藏：同一 (pmid 或 doi) 已存在则返回已存在记录（幂等），不新建

【实施步骤】
1. 保存元数据记录（pmid/doi/title/journal/year + source_search_id 溯源）；
2. 按 PMID/DOI 匹配本地文档（document/matcher.py，纯函数，误匹配防护）；
3. 允许用户手动绑定 PDF（link-local-pdf，记录 document_id + local_pdf_available）；
4. 记录全文状态（基于可验证信号 + reason，不自动下载）；
5. 不自动越权下载（无任何自动抓取逻辑）；
6. 防止重复收藏（幂等：同 pmid/doi 返回已有记录）。

【必须处理的异常】
- 同一论文多个 PDF（绑定新 PDF 时记录变更而非静默覆盖，或明确最后绑定生效并记录）；
- 误匹配（matcher 只做精确 PMID/DOI 匹配，不做模糊匹配）；
- 开放全文链接失效（状态判定不依赖实时链接可用性，标注 reason）；
- 版权边界（付费内容 = metadata_only/unavailable，绝不下载）。
