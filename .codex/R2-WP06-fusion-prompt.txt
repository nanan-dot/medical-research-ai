【本任务目标】
R2-WP06：文献去重——跨检索来源的重复识别、合并与撤销。

【来源需求】
### 去重优先级
1. PMID；
2. DOI；
3. 标准化标题；
4. 作者 + 年份；
5. 人工确认。

### 业务规则
- 不自动永久删除不确定重复项；
- 显示合并依据；
- 保留来源检索任务；
- 用户可撤销。

### 验收
- 构造重复数据集；
- 自动识别明确重复；
- 模糊重复进入人工确认；
- 不误删不同论文。

【与 skills 的融合点（必须体现）】
1. **manage-refs 引用去重哲学**：去重只产生"合并决策"，永不物理删除原始记录。
   每条被合并记录保留 source_search_ids（来源任务）与 canonical_record_id（保留记录），
   撤销 = 删除合并决策，原始数据原样回归。
2. **合并依据可解释（反幻觉延伸）**：每个 duplicate_group 携带 match_method
   （pmid/doi/title_normalized/author_year/manual）与 confidence（明确/模糊），
   前端展示合并依据，禁止虚构匹配理由。
3. **标题标准化**（manage-refs 规范）：小写、去标点、去多余空白、统一常见缩写
   （如 "&" → "and"）、去除尾随句点；DOI 标准化（小写、去前缀 https://doi.org/）。
   标准化函数必须是纯函数、带单测。

【建议文件范围】
- app/modules/literature_search/dedup.py（去重核心：标准化 + 匹配 + 分组）

【接口要求】
- POST /literature-search/{id}/deduplicate（对指定任务的结果执行去重）
- GET /duplicate-groups（列出去重组，含人工待确认）
- POST /duplicate-groups/{id}/resolve（人工确认：保留某条 / 全部保留 / 全部合并）

【数据与状态要求】
- duplicate_group：id / match_method / confidence / created_at / status（pending_resolution/auto_merged）
- 组内记录：record_id / canonical_record_id（合并后指向保留记录）/ source_search_ids
- resolution：resolved_at / resolved_action / resolved_by（人工确认信息）

【实施步骤】
1. 实现 PMID 精确匹配（最高优先级）；
2. DOI 标准化匹配（大小写/前缀统一）；
3. 标题标准化候选（纯函数 + 单测）；
4. 作者年份辅助（作者第一作者 + 年份相同 = 模糊候选）；
5. 不确定组人工确认（confidence=fuzzy 的不自动合并）；
6. 合并保留来源（canonical + source_search_ids）；
7. 支持撤销（删除合并决策即回归）。

【必须处理的异常】
- 误合并（模糊组必须人工确认，不自动删）；
- 标题翻译版本（不同语言标题 = 模糊候选，不自动合并）；
- 早期在线与正式版（same DOI/PMID = 明确重复；仅标题相似 = 模糊）；
- DOI 缺失（退化为标题/作者年份匹配）。
