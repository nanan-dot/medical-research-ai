# FE-03.5：Paper Analysis Workspace 视觉重构（最终执行版）

## 项目背景

MedAI 医学科研智能助手，前端 `frontend/`（Vue 3 + TypeScript + Vite）。
FE-01.5 浅色科研工作区已确定；FE-03 论文分析页面已实现但视觉是"在线 PDF 阅读器 + 后台详情页"。

本轮目标（只优化视觉与组件结构，不加功能、不改后端、不新增 API）：

> 从"PDF 阅读器"变为"AI 辅助医学科研阅读工作空间（Research Analysis Workspace）"。
> 参考：PaperQA / Elicit / Perplexity Academic / Notion Research / Nature 阅读体验。

## 铁律：数据真实性边界（后端未完成部分不得伪造）

后端 PaperAnalysis API 真实返回结构（已核验）：
- `PaperAnalysisRead`: id, document_id, analysis_status, template_version, model_version, generation, structured_result, sources, pending_confirmations
- `StructuredPaperResult` 17 个字段：basic_information, one_sentence_conclusion, research_background, research_question, study_type, population, sample_size, intervention_or_exposure, comparator, primary_outcome, statistical_methods, main_results, innovations, limitations, next_questions, original_evidence, pending_items（每个是 AnalysisField: value + kind[fact/summary/inference/not_found] + source_indices）
- `PaperSource`: source_id, title, citation, page_start, page_end, excerpt, score
- **不存在**的字段：keywords/标签、journal/DOI/publication_date、citation_count、章节阅读状态

前端三态规则（严格执行）：
- **LIVE**：真实字段 → 直接展示
- **UNAVAILABLE**：后端不存在的字段 → 显示"未提供"/"待接入"，绝不硬编码伪造
- 不伪造医学数据、不虚构标签、不假装 PDF 可打开

具体边界落实：
| 提示词要求 | 落地方式 |
|-----------|---------|
| 标题/作者 | basic_information.value + 文档元数据 |
| 期刊/年份/DOI | 后端无字段 → 显示"未提供"（占位但诚实） |
| AI 分析状态 | analysis_status（pending/analyzing/succeeded/failed）→ 状态徽章 |
| Model | analysis.model_version（真实字段，直接显示） |
| Evidence 数量 | sources.length |
| 章节阅读/AI 状态 | 从 sources[].page_start 推导：有来源引用=已分析；无=未覆盖 |
| Key Findings | main_results + innovations + one_sentence_conclusion 分组（真实字段，不虚构条数） |
| 置信度 | kind 映射：fact+有source=High；summary=Medium；inference/not_found=Needs verification |
| 标签 | 无 keywords 字段 → 空状态显示"暂无标签"，不做示例标签 |
| Study Type/Sample Size 等元数据 | structured_result.study_type.value / sample_size.value（真实） |
| Citation Count | 后端无 → 显示"未提供" |
| Jump to source | 定位到证据卡片/高亮片段（文档原文件打开是 UNAVAILABLE，不假装） |
| 创建组会汇报 | 保持 FE-06 前 UNAVAILABLE 提示（沿用现有文案） |

## 布局

三栏（非等宽）：
- 左 18%：Paper Structure Navigator
- 中 57%：AI Research Report
- 右 25%：Evidence Context Rail

响应式（沿用 FE-01.5 断点）：
- <1100px：右侧证据栏折叠为底部抽屉（保留触发按钮）
- <900px：左侧导航隐藏

## 组件拆分（每文件一职责）

```
frontend/src/components/paper/
  PaperHeader.vue        # 顶部工具栏（轻量：返回/Analyze/创建组会汇报/Export/More）+ AI 状态徽章
  PaperOutline.vue       # 左侧章节导航（Abstract/Intro/Methods/Results/Figures/Discussion/References，显示页码+状态）
  ResearchBrief.vue      # 中央顶部：论文信息区（标题/作者/期刊/年份/DOI/AI状态/置信度概览）
  InsightBlock.vue       # 中央分析章节块（Research Block：章节标题+why+Evidence 页码引用）
  EvidenceRail.vue       # 右侧证据栏（Evidence Context Rail）
  EvidenceCard.vue       # 单条证据卡（Page/Type/原文/置信度徽章/Jump）
  SourceLocator.vue      # 来源定位（页码/章节引用行）
  ConfidenceBadge.vue    # 置信度徽章（High/Medium/Needs verification 三态色）
  PaperMetadataBar.vue   # 底部元数据条（Study Type/Sample Size/Publication Date/Citation Count/Evidence Level）
```

## 视觉规范（保持 FE-01.5）

- 页面底 #F7F9FC / 内容 #FFFFFF / Primary #2563EB / 文字 #0F172A / 边框 #E5E7EB
- 边框 1px、弱阴影（rgba(15,23,42,0.06)）、圆角 12px
- 禁止：PDF 阅读器感、后台详情页、大量 Card、数据 Dashboard、聊天气泡式 AI
- 动画：hover 150ms；禁粒子/炫光/无限动画
- 中央阅读区域是核心、右侧证据栏是核心能力、每个 AI 结论可追溯

## 页面流程

1. 无分析时：保留"输入文档 ID → 生成报告"的引导空状态（简洁科研风）
2. 有分析时：显示完整三栏工作台
3. 顶部工具栏：Analyze（重新生成）/ 创建组会汇报（UNAVAILABLE 提示）/ Export（导出 Markdown，沿用现有 exportUrl）/ More

## 验收标准

- typecheck + test + build 全部通过
- 中央阅读区成为核心；右侧证据栏成为核心能力；每个 AI 结论可追溯（页码/章节/来源）
- 与浅色科研系统一致；长时间科研使用舒适
- 不伪造任何后端不存在的数据
