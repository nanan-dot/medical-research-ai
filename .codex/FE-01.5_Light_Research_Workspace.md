# FE-01.5：Light Research Workspace Design System 重构

## 项目背景

项目：医学科研智能助手平台（MedAI）

产品定位：面向医学科研人员的 **AI Research Workspace**，而不是传统后台管理系统。

当前已有：
- FE-00：仓库审查与前端实施计划
- FE-01：Design System 与应用外壳
- FE-02：工作台、知识源、文档库模块

当前问题：视觉方向偏向企业后台 / 医疗管理系统 / Dashboard 数据中心，与目标产品定位不一致。

本轮目标：**重新设计整个前端视觉体系**——将"深海蓝后台式导航"调整为"浅色科研工作空间（Light Research Workspace）"。

---

## 一、产品视觉重新定位

### 错误方向（禁止）
- 医院 HIS 系统
- 企业 ERP
- BI 驾驶舱
- 普通 Admin Dashboard
- 大量统计 Card
- 深色后台

### 正确方向（参考）
- Notion / Linear / Perplexity Academic / PaperQA / Elicit
- Nature 论文阅读体验
- Apple 产品设计语言

关键词：`Scientific Clean Academic Intelligent Minimal Trustworthy`

产品感觉：用户打开页面后应该感觉"这是我的医学科研工作空间"，而不是"这是一个医院管理后台"。

---

## 二、整体布局重新设计

```
┌──────────────────────────────┐
│                              │
│ Sidebar    Main Workspace   Context Rail
│                              │
└──────────────────────────────┘
```

比例：Sidebar 18% / Main Workspace 67% / Context Rail 15%

---

## 三、Sidebar 设计规范

- 背景色：废弃 `#071A33`，改为 `#F8FAFC` 或 `#F5F7FB`
- 不要：黑色菜单、强烈视觉分割、大面积颜色块
- 应该：轻、安静、科研工具感

### Sidebar 结构
1. **顶部 Logo**：`MedAI / 医学科研智能助手`，高度 72px，底部细分割线
2. **研究空间**：工作台 / 论文分析 / 证据问答
3. **知识资产**：知识库 / 文档库 / 文献检索 / 多论文比较
4. **科研产出**：研究方向 / 写作与汇报 / 组会汇报
5. **智能工具**：Agent 实验室 / 评测中心
6. **底部固定**：任务中心 / 设置 / 模型状态 / 用户信息

---

## 五、导航交互设计

- 默认：文字+Icon `#64748B`
- Hover：背景 `#F1F5F9`
- Active：**不要深蓝色块**，用背景 `#DBEAFE` + 文字/Icon `#2563EB`（Notion 侧边栏效果）

---

## 六、页面背景系统

- 页面背景：`#F7F9FC`（不要纯白，减少阅读疲劳）
- Card：背景 `#FFFFFF`，边框 `1px solid #E5E7EB`，阴影非常弱（禁止强阴影）

---

## 七、颜色系统

| Token | 色值 | 用途 |
|-------|------|------|
| Primary 医学蓝 | `#2563EB` | 主按钮 / Link / Active |
| Secondary 科研青 | `#0EA5E9` | AI 状态 / 检索状态 |
| Success | `#16A34A` | 完成状态 |
| Warning | `#D97706` | 等待确认 |
| 标题文字 | `#0F172A` | |
| 正文 | `#64748B` | |
| 辅助 | `#94A3B8` | |

---

## 八、Typography

- 字体：Inter / SF Pro / Noto Sans SC
- 标题有医学科研感，避免互联网大标题
- 层级：H1 32px / H2 24px / H3 18px / 正文 14-16px

---

## 九、顶部 Header

不要传统后台 Header，应该是**科研入口区域**：
- 左："下午好，Researcher 👋 专注医学文献，洞察研究本质"
- 右：模型状态 / 隐私状态 / 用户头像

---

## 十、首页搜索框（核心入口）

- 高度 60px，宽度 80%+，白色，圆角 12px，1px 边框，轻阴影
- 内容："搜索论文、笔记、研究方向、任务... Ctrl + K"

---

## 十一、功能入口

不要 Dashboard Card，改为 **Research Capability Entry**（横向入口，高 90px）：
- 论文分析：深入解析医学论文
- 证据问答：基于证据链回答
- 文献检索：构建医学检索任务
- 多论文比较：发现研究差异
- 知识库：管理科研资产
- 组会汇报：自动生成材料

---

## 十二、工作台首页布局

```
最近研究(35%)    任务中心(35%)    知识库状态(30%)
```

- **Recent Research**：不要 Card，用 Linear Issue 列表（PDF Icon + 标题 + 类型 + 时间）
- **任务中心**：突出 AI 工作流，显示 状态/进度/时间（如"文献检索任务 免疫治疗 AND 肝癌 处理中 60%"）
- **知识库状态**：不做 BI，不做大数字；体现科研资产（论文/笔记/标签/存储空间/30天增长趋势）

---

## 十六、组件调整

禁止万能 `DashboardCard.vue`，拆分为：

---

## 十七、动画规范

- 允许：hover 150ms；页面进入 fade + translateY
- 禁止：粒子动画 / 炫光 / 大面积渐变 / 无限动画

---

## 十八、响应式

- 桌面：完整布局
- Tablet：Sidebar 折叠
- Mobile：Bottom Navigation

---

## 十九、代码规范

遵守 FE-00：TypeScript / 组件独立 / API 与 View 分离 / 不新增后端 / 不伪造医学数据 / LIVE-MOCK-UNAVAILABLE 保持。

---

## 二十、最终验收标准

打开首页 3 秒内用户必须理解：
1. **我是谁**：医学科研人员
2. **我能做什么**：分析论文、搜索证据、管理知识、生成科研成果
3. **下一步**：继续当前研究

像医院后台 = 失败；像医学科研 AI 工作空间 = 成功。
