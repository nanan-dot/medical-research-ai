# FE-02：工作台、知识源、文档库与文档详情提示词


## 全阶段共同背景

项目：医学科研智能助手平台  
当前后端进度：**R2-WP02 已完成**  
前端目标：先完成整体产品界面，再随着后端任务推进逐步替换 Mock Adapter。

必须区分三种功能状态：

- `LIVE`：仓库中已经存在并经过验证的真实接口；
- `MOCK`：高保真前端原型，使用类型安全的 Mock Adapter；
- `UNAVAILABLE`：当前不能合理模拟的能力，明确显示“待接入”，不得伪装成功。

R2-WP03及之后、R3、R4的后端能力，在仓库没有真实接口时不得擅自补写后端，不得把 Mock 医学数据包装成真实检索结果。

视觉参考文件建议放在：

```text
docs/design/医学科研智能平台界面总览.png
```

总体风格：

- 月之暗面式稳定产品结构；
- 深海军蓝左侧导航；
- 浅色论文纸张感工作区；
- Awwwards/Behance的构图与留白；
- Dribbble级组件细节；
- Nature、Science、PubMed式医学科研专业感；
- 统一右侧证据与上下文栏；
- 禁止普通后台模板、同质Card墙、廉价霓虹和无意义特效。

共同代码规则：

1. 一个文件只负责一个功能；
2. 禁止所有代码写在一个文件；
3. 每个组件独立封装；
4. 复杂逻辑添加有意义的中文注释；
5. 使用TypeScript；
6. API、Types、Store、Composable、View分层；
7. 不生成无意义代码和未来空壳；
8. 不伪造医学论文、DOI、PMID、页码、统计数据和真实接口结果；
9. 实际运行类型检查、Lint、测试和Build；
10. 未实际运行的命令不得声称通过；
11. 每轮只完成当前FE任务；
12. 完成后立即停止，不自动进入下一任务。

# 可直接复制给Codex

```text
你现在执行FE-02：工作台、知识源、文档库与文档详情。

一、前置条件

- FE-00、FE-01完成；
- AppShell和Design Token可用；
- 必须读取FE-00接口清单；
- 真实接口存在时接LIVE；
- 不存在时使用Mock Adapter并显示原型状态；
- 不新增后端接口。

二、本轮页面

1. 工作台首页；
2. 知识源管理；
3. 文档库；
4. 文档详情。

三、工作台首页

页面目标：用户进入后十秒内知道下一步。

位置：

顶部：
- 问候；
- 当前模型；
- 隐私状态；
- 一个主要操作“继续上次研究”。

中央：
- 科研问题输入；
- 导入论文；
- 新建分析；
- 新建组会汇报；
- 最近论文和会话；
- 当前运行任务；
- 知识库健康状态。

底部：
- 当前阶段已开放能力；
- R2后续能力只能显示原型标签或隐藏。

禁止将首页做成统计Card墙。

四、知识源管理

实现：

- 文件夹知识源；
- Obsidian知识源；
- 临时导入；
- 路径、类型、状态、文档数、同步时间；
- 手动同步；
- 启用/停用；
- 同步错误；
- 重试；
- 移除系统记录；
- 明确“不删除原始文件”。

错误详情显示在统一Context Rail。

五、文档库

实现：

- 左侧筛选；
- 紧凑文档列表；
- 来源、类型、解析状态、索引状态；
- 搜索；
- 排序；
- 批量选择；
- 批量索引；
- 分析；
- 提问；
- 打开文档详情；
- 打开原文件。

避免大卡片列表。

六、文档详情

布局：

- 顶部：返回、标题、打开原文件、分析、提问；
- 中央：PDF或Markdown预览；
- 右侧：元数据、解析状态、索引状态、错误；
- 支持逐页导航；
- 扫描PDF显示“暂不支持OCR”；
- 删除操作只删除系统记录或索引，不删除原文件。

七、建议组件

- HomeHero；
- PrimaryNextAction；
- KnowledgeHealth；
- RunningTasks；
- SourceList；
- SourceRow；
- AddSourceDialog；
- SyncSummary；
- DocumentFilters；
- DocumentTable；
- DocumentStatusGroup；
- BulkActionBar；
- DocumentViewer；
- PageNavigator；
- DocumentMetadata；
- ParseStatusPanel；
- IndexStatusPanel。

八、数据层

- 页面不得直接调用Axios；
- 每个领域有独立API文件；
- Store只保存跨页面状态；
- 列表筛选尽量放URL Query；
- Mock数据只能使用明显虚构标识，如“演示文档A”，不得使用伪造真实论文。

九、状态

每页实现：

- Loading；
- Skeleton；
- 空状态；
- 失败；
- 重试；
- 部分同步成功；
- 文件外部删除；
- 路径不可访问；
- 后端不可用；
- 未配置模型；
- 未建立索引。

十、测试

至少覆盖：

- 空知识库；
- 添加来源表单校验；
- 同步错误；
- 文档筛选；
- 批量选择；
- 状态显示；
- 文档详情页码；
- 原文件删除后的提示；
- Mock与LIVE状态。

十一、验收

- 页面符合草图布局；
- 知识源、文档和状态关系清晰；
- 不删除原文件；
- 工作台主任务明确；
- API调用与Mock分层；
- 类型检查、Lint、测试和Build通过；
- 更新实施状态。

完成后只说明下一步FE-03，不执行。
```
